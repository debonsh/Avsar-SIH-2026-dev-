No DESIGN.md exists. Theme drift noted under 12.

Design read: app shell + data panels for an internship/upskilling portal (BAMS + tech students), dark zinc system with blurple action accent, dial ENERGY 2 / RHYTHM 2 / MOTION 1 (carried from audit-001; MOTION 1 means hover states plus at most one hero reveal, everything else static).

R-31 one-line reasons (kept here so fixes stay honest):
- Color: zinc-950 panels carry dense app content; blurple marks only action and progress so the eye lands on what to do next.
- Layout: one max-w-5xl column because every screen is a work queue, not a marketing story.
- Type: Archivo display for headings (voice), Inter for body (reading), mono only for measurement (scores, counts, urls).
- Radius: lg on actions, xl on panels, md on pills, so control vs container vs tag read apart.
- Motion: near-zero by default because students revisit these screens daily; motion that repeats daily is noise.

## Findings (pick numbers to fix; unmentioned numbers are not touched)

   Evidence: `Card` is `bg-zinc-950`; `Public.jsx`, `Programs.jsx`, `Resume.jsx`, `Journey.jsx` render `text-stone-500/700/800` and `bg-white/bg-stone-50` inside it.
   Fix: give `Card` an explicit `tone` (dark default, light opt-in), move light callers to it, verify AA.
9. [HIGH] No visible focus indicator on any control (R-32).
   Evidence: `buttonVariants`, `inputCls`, `Badge/Chip`, `Slot/Link` paths have zero `focus-visible` classes.
   Fix: add one `focus-visible` ring token (outline blurple, offset 2) to Button, inputCls, and interactive slots.
10. [HIGH] StatusBar/AsciiRule 11px `text-zinc-600` on dark fails AA (R-25).
    Evidence: `ui.jsx:301,304,313` mono 11px uppercase zinc-600 needs 4.5:1, lands near 3.x:1 on zinc-950.
    Fix: lift both to zinc-400, keep tracking.
11. [HIGH] SyllabusTable returns null on empty, no empty state (R-27).
    Evidence: `ui.jsx:398` `if (!data.length) return null`.
    Fix: return `Empty` with cause plus the one action that fills it.
12. [HIGH] No direction file plus header/drift vs audit-001 (R-37).
    Evidence: no DESIGN.md; header comment claims "light theme, herb-green" while code is dark zinc + blurple; audit-001 dials assumed warm paper.
    Fix: correct the header to one true line; DESIGN.md itself is the user's call.
13. [MEDIUM] Mono uppercase wide-tracked labels on five components with no written purpose (R-06).
    Evidence: StatusBar, AsciiRule, Ticket header, TermWindow body/url, SyllabusTable thead all `font-mono text-[11px] uppercase tracking-widest`.
    Fix: keep mono for measurement (counts, scores, url), switch prose labels to semibold sans; reason in R-31 block above.
14. [MEDIUM] Card vs Ticket vs TermWindow are the same shell (R-14).
    Evidence: all three `rounded-xl border border-zinc-800 bg-zinc-950`, differing only by header row.
    Fix: document one hierarchy reason each and separate them visually, or merge Ticket into Card with a header prop.
15. [MEDIUM] Blurple on buttons, Meter, badges, Ticket status with no dose rule (R-01).
    Evidence: `ui.jsx:54,108,207,331` spread accent across action, progress, tag, and frame label.
    Fix: accent rule (actions + progress only; Ticket status falls back to zinc) and apply.
16. [MEDIUM] Reveal/Meter/Donut/CountUp animate on every use with identical params (R-19).
    Evidence: Reveal 0.45s y-14 `whileInView` everywhere, Meter/Donut `whileInView`, CountUp 0.6s; contradicts MOTION 1.
    Fix: document dial (hero + first proof reveal only, rest static), default delay 0, callers opt in.
17. [MEDIUM] Palette exceeds cap with duplicated tokens (R-29).
    Evidence: blurple + emerald + amber + green + red + blue + six Donut hexes; `badgeVariants` alone has five tones; `#1e7a4c/#c77b21` hardcoded in both Radar and Donut.
    Fix: tokenize to zinc + blurple + semantic states only, derive Donut/Radar from tokens, drop blue-vs-blurple and green-vs-emerald duplicates.
18. [LOW] rounded-xl on everything, inners ignore concentric radius (R-11).
    Evidence: Button, input, Card, Badge, Skeleton, Empty, Ticket, TermWindow, table pills all `rounded-xl`; TermWindow url pill is square inside a rounded frame.
    Fix: radius scale (actions lg, panels xl, pills md) plus outer-equals-inner-plus-padding on Ticket/TermWindow inners.
19. [LOW] Tap targets, tooltips, and table/radar details (feel-better checklist + C-4).
    Evidence: `sm:h-8` (32px) and `size-10` icon (40px) under the 44px target; VaidyaLevel `size-6` dots with mouse-only `title`; ErrorBox missing `rounded-xl`; table `th` missing `scope`; Radar truncates long labels with no full-name fallback.
    Fix: 44px minimum on interactive sizes, static legend or keyboard-safe VaidyaLevel, rounded-xl on ErrorBox, `scope="col"`, `<title>` per Radar axis.
20. [LOW] Stale header plus banner comments (antislop-code + R-31).
    Evidence: header claims light/herb-green (false) with em dash; `// --- system24 ...` and `// --- ayush tokens ...` are decorative banners; keeper why-comments are Radar truncation, Donut stagger, legacy aliases.
    Fix: one true header line, plain-line banners, no em dashes, code untouched.
21. [LOW] Dead code and token drift (C-1).
    Evidence: CountUp `ref` never read; `DONUT_COLORS_EXPORT` duplicates `DONUT_COLORS`; SAGE/GOLD tokens are light-theme leftovers vs the zinc system; `Chip` duplicates `Badge`.
    Fix: drop unused ref, export one color token, delete or wire SAGE/GOLD, keep Chip only with a one-line why.
