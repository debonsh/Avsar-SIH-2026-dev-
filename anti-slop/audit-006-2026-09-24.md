# Anti-slop audit 006 — light-theme contrast pass — 2026-09-24

Mode: AFTER, autonomous (user: dark-only elements break in light themes).
Scope: full grep of `text-white`, `text-zinc-600/700/800/900`,
`text-emerald-100/200/300/900/950` across `src`, plus full reads of the
never-audited pages (Labs, Shortlist, Challenges, CareerGps), the rebuilt
MarketPulse/Faculty, charts, Receipt, XpMeter, Welcome, shell header/footer,
coach-widget. Previous audits: 001-005 (1-39). Numbering continues from 40.

Method: every hardcoded utility was checked against the four remap layers in
`index.css` (ayush-light, ayush-dark, tech-light, tech-dark). A utility is
safe only if it reads in all four. Zinc-50..600 and stone-on-light-panels
pass; unmapped zinc-700+, emerald-300, and red-200 do not.

## Findings (all fixed this pass)

40. [HIGH] Shell ayush brand + footer unreadable in ayush-dark. Evidence:
    `shell.jsx` logo and footer brand used `text-emerald-950`, which no remap
    touches, on a header/footer that goes dark. Fix: `text-emerald-800`
    (maps light in ayush-dark, stays dark in ayush-light).
41. [MED] ErrorBox invisible in tech-light. Evidence: `ui.jsx` ErrorBox used
    `text-red-200`, unmapped in tech-light, on a panel both lights flip pale.
    Fix: `text-red-300` (both lights map it dark red, both darks keep it light).
    Note: an ayush-dark red flip I first suspected does not exist (grep proved
    it), so no CSS change was needed.
42. [MED] Welcome Vaidya badge + legend washed out in light themes. Evidence:
    `bg-emerald-500/15 text-emerald-300` and a bare `text-emerald-300` legend,
    both unmapped in the lights. Fix: badge becomes `bg-emerald-100
    text-emerald-800` (the XpMeter pattern, proven in all four); legend text
    becomes zinc-400 with the emerald dot keeping the hue.
43. [LOW] Shortlist identifiable-link warning `text-amber-500/80` weak on paper.
    Fix: `text-amber-600` (solid in lights, readable in darks).
44. [LOW] CareerGps sim arrow `text-zinc-700` unmapped in darks. Fix:
    `text-zinc-500`.
45. [LOW] Jobs apply pill `min-h-[36px]` (missed in audit-005). Fix: 44px.
46. [LOW] Shell ayush footer meta `text-stone-400` (~2.3:1 on paper). Fix:
    tagline, both section heads, mobile label, tabbar links to `text-stone-500`
    (4.6:1 on paper, remapped light in ayush-dark).
