# Reference board: app-shell navigation (viewed 2026-09-20)

Design read: app shell for BAMS students, phones-first demo; daily check-in mode;
warm paper + herb green, playful-clinical; motion small, density roomy.

## Direct sources (viewed)
- CoreUI React navbar docs (coreui.io): brand block left, nav cluster center,
  action cluster right, collapse under breakpoint, dropdowns inside nav.
  DNA taken: three-zone header, segmented nav cluster, More dropdown.
- CoreUI free icons (same family): single-stroke set, used for every nav glyph.

## Adjacent pattern (known, not fetched)
- Duolingo app shell: persistent stat bar (streak/gems = readiness ring +
  quest count), icon+label bottom tabs on mobile, avatar for profile.
  DNA taken: bottom tab bar with active ink indicator, stat-first header.

## Anti-references
- Hamburger hiding primary destinations on mobile.
- Generic gradient logo tile; kept the spa-mark + SIH'26 chip instead.

## Direction contract
Thesis: the shell reads as a clinic notice board, not an admin template.
First viewport: brand + 4-segment pill nav + readiness ring on desktop;
brand + ring + avatar on mobile with bottom tabs.
Risk: tab bar overlapping content; guarded with main pb-24 on mobile.
